# Factory Image Replacement Slots

The Factory Strength section uses six replaceable image slots.

To replace a factory photo, overwrite the matching file and keep the same filename:

- `public/factory/factory-01.jpg`
- `public/factory/factory-02.jpg`
- `public/factory/factory-03.jpg`
- `public/factory/factory-04.jpg`
- `public/factory/factory-05.jpg`
- `public/factory/factory-06.jpg`

Recommended image format:

- JPG image
- Landscape images work best, but portrait images are supported
- Keep each image under 1 MB when possible
- Do not rename the files unless the website code is updated

After replacing files, ask Codex to publish the site again.
